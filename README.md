# CLASH: Races at the Frontline

An early, responsive command-screen prototype for a cross-species multiplayer FPS concept.

## Preview

Open `index.html` in a browser. No build step or package install is required.

## Prototype interactions

- Choose a Human, Grey, Reptilian, or Insectoid lineage.
- Select 5v5, 10v10, 15v15, 20v20, or 25v25.
- Open a local matchmaking preview or configure a room and receive a sample room code.

These interactions are front-end demonstrations. There is no online matchmaking, account system, 3D gameplay, or room server yet. Those are later milestones.
